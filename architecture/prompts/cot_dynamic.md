# id: COT-DYN · версия 1.1 · паттерн: Chain-of-Thought
Построй динамическую диаграмму (C4_Dynamic) сценария «{{сценарий}}» по контрактам
участников (таблицы контрактов приложены). Рассуждай по шагам и покажи результат
каждого шага кратко, затем выдай код.

Шаг 1. Выпиши участников: роли, контейнеры, внешние системы. Сверь каждый ID с глоссарием.
Шаг 2. Упорядочь вызовы по времени. Для каждого вызова укажи: кто → кому, функция или эндпоинт.
Шаг 3. Проверь, что каждый эндпоинт есть на диаграмме компонентов API (L3).
        Нет — отметь «РАСХОЖДЕНИЕ» и не добавляй вызов молча.
Шаг 4. Отметь асинхронные переходы: задача через outbox — $tags="async".
Шаг 5. Назначь протокол каждому вызову (правило 4 системного промпта).
Шаг 6. Сверь: нумерация сквозная, нет Rel_D/Lay_, у каждой стрелки есть протокол.

Ответ: (а) таблица «шаг | вызов | протокол | источник контракта»,
(б) список расхождений, (в) код диаграммы.
